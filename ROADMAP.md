# Roadmap

The plan, with scope and an exit test for every phase, lives in section 7 of
`docs/ASSESSMENT_AND_PLAN_2026-11.md`. This page is the index.

The earlier roadmap listed ten phases by system and marked Phases 2-8 as built. They
were built as code and not as a game; see the assessment.

| Phase | Delivers | Status |
|---|---|---|
| 0. Truthful baseline | Everything that exists is visible and stops crashing; checks in the repo | Implemented 2026-11-16, awaiting playtest and commit |
| 1. Game shell and state | Menu, character creation as new game, game over, seeded dungeons, real saves, placeholder art at 32 px | Next |
| 2. Combat core | One combatant model, action economy, weapon-based action bar, ranged attacks, 5e armour, durability wear, bestiary and behaviours, combat simulator | Needs the durability decision |
| 3. Dungeons | More rooms with roles, doors, chests, traps, line-of-sight vision, a goal and an exit | |
| 4. Town and economy | Town screen, world map, NPCs, shops, repair, quest turn-in; main quest completable | |
| **Milestone 1** | **First playable**: menu to character to town to dungeon and back | |
| 5. Class, magic and item depth | Four classes that play differently at levels 1-5, about 35 spells done properly, companions as party members | |
| 6. Presentation | Own art replacing placeholders, UI theme, music and sound | |
| **Milestone 2** | **Vertical slice**: one to two hours that represent the finished game | |
| 7. Zone 1 content | Content pipeline, then towns, quests, bestiary, crisis | |
| 8. Early Access preparation | Builds, performance, accessibility, store page | |

Shelved: multiplayer. Deferred: levels above 5, names and lore.
